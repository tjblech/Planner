Runway keeps your tasks in this browser by default. Connect a free Supabase project and it syncs everywhere you sign in. Your credentials stay in this browser and go straight to your own project.

One-time setup. In your Supabase project open the SQL editor, paste this, and run it. Row level security means each account only ever sees its own rows.

create table public.tasks (
  id       text primary key,
  user_id  uuid not null default auth.uid()
           references auth.users on delete cascade,
  data     jsonb not null,
  updated  timestamptz not null default now(),
  deleted  boolean not null default false
);

alter table public.tasks enable row level security;

create policy "own rows" on public.tasks
  for all
  using (auth.uid() = user_id)
  with check (auth.uid() = user_id);

The anon key is meant to be public and is safe to commit, because row level security is what actually protects the data. Under Authentication → Providers → Email, turn off "Confirm email" if you want to sign in immediately without a confirmation step.
